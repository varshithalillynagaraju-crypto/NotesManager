# Notes Manager

A simple Java console-based Notes Manager that uses file handling to store and retrieve notes.

## Features
- Add notes and save them to a text file
- View all saved notes
- Menu-driven interface
- Uses FileWriter, FileReader, and BufferedReader

## Technologies Used
- Java
- File Handling

## How to Run

1. Compile the program:
   javac NotesManager.java

2. Run the program:
   java NotesManager

## Learning Concepts
- FileWriter
- FileReader
- BufferedReader
- Exception Handling
- Loops and Switch Statements
- User Input using Scanner
